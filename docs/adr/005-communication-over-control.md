# ADR 005: Product Framing — Communication over Control

## Status

Accepted

## Context

Early CPO drafts emphasized proof, approval, and reliability scores. That framing risks provider resistance and mis-sells the real job: bilingual alignment and better guest service.

## Decision

- Position Leblebee as a **shared ops channel** with handoff context
- Photos = handoff / context, not courtroom evidence
- Host actions: acknowledge, follow-up, reopen if another visit is needed — avoid “approve/reject” theater
- Defer reliability scores, marketplace directory, and performance analytics

## Consequences

- Copy and UX components use collaborative language
- Soft nudge for photos on cleaning tasks rather than hard-gate everything on day one (configurable later)
- Companion features optimize for “don’t forget” and clarity, not surveillance
